# Stats and wiki review — 2026-09-11

Scope: the new `stats --mode alignment` and `--out_file` paths, backward
compatibility of default sequence statistics, and current wiki command guides.
No GeneGalleon workflow call sites or localization model weights were changed.

## Findings and fixes

- AMAS rounds missing percentage after dividing by the matrix cell count and
  then multiplying by 100. Multiplying first changed 23/320 missing cells
  from 7.187% to 7.188%. The implementation now preserves AMAS's operation
  order; `dna_rounding` is an independently generated reference fixture.
- Empty alignment IDs are rejected, in addition to duplicate IDs, invalid
  alphabets, zero-length records and unequal alignment lengths.
- Alignment mode validates the common thread argument even though its
  implementation runs serially. Negative requests no longer pass silently.
- Failure injection verifies that named sequence and alignment reports preserve
  the original destination on write failure. Input/output collisions fail.
- Default text output is unchanged. Protein alignment summaries explicitly
  report AT/GC as `NA`; DNA summaries preserve the documented AMAS legacy GC
  semantics, including the all-missing GC=1 convention. That value is not a
  measured biological GC fraction.

## Wiki review

All 27 command pages were compared with the current parser's option names;
references to other commands and explicitly unsupported options were checked
in context. Eleven self-contained documented command examples were executed;
all succeeded and their supplied expected sequence outputs matched.

The wiki now includes page-end paper references for applicable methods,
software and data resources. Generic utilities with no separate designated
method paper link to the project citation guidance instead of attributing
new algorithms to unrelated papers. Paper identities were checked against
publisher/primary sources and DOI metadata. Dataset/model papers are labeled
by their role; they are not presented as validation of CDSKIT-trained models.

The review corrected the default-model overview, missing filelock/PyYAML
requirements, context-dependent stop wording, the legacy CNN's optional
runtime decision overrides, and the distinction between scores and calibrated
probabilities. The Bioconda 0.27.0 recipe was rechecked; its packaging limitations
remain. Wiki-internal page links resolve to existing sources and bibliographies
are at page ends. The public wiki was behind the main repository's ESM2 model
page and prediction guide; these are included in publication.

Historical experiment tables were retained as historical results, not rerun or
recast as independent contemporary model validation. Live database downloads,
large-model inference and model retraining were not part of this code review.
