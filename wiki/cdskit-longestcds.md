# cdskit longestcds (deprecated)

`cdskit longestcds` is a deprecated alias of
[`cdskit longestorf`](https://github.com/kfuku52/cdskit/wiki/cdskit-longestorf).
It accepts the same options and performs the same six-frame ORF search, but
writes a deprecation warning. Use `cdskit longestorf` in new workflows.

The alias also supports `--selection complete-first|longest` and `--report`;
see [longestorf selection and provenance](https://github.com/kfuku52/cdskit/wiki/cdskit-longestorf).

## Citation

No separate method paper is designated for this utility. Report the CDSKIT
version, command and options; see [citing CDSKIT](https://github.com/kfuku52/cdskit/wiki#citing-cdskit).
